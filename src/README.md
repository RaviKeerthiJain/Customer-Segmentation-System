# Customer Segmentation using Clustering

## 📌 Project Overview
This project segments customers into different groups using K-Means Clustering based on customer income and spending behavior.

---

## 📌 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## 📌 Machine Learning Algorithm
- K-Means Clustering

---

## 📌 Features
- Customer Segmentation
- Elbow Method
- Cluster Visualization
- Gender Distribution Analysis
- Cluster Summary
- Customer Type Analysis

---

## 📌 Dataset
Dataset used from Kaggle:
Mall Customer Segmentation Dataset

---

## 📌 Output
The system groups customers into meaningful clusters for marketing and business analysis.

Generated Outputs:
- Elbow Method Graph
- Customer Cluster Visualization
- Gender Distribution Graph
